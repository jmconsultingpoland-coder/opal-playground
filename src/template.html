    Your code stays on your computer

    Everything runs in your browser. The code you type is never uploaded, stored on a server or shared. The page keeps an unsent draft in your own browser only.

    Feedback sends only what you see in the feedback form. Code is attached only when you tick the box, so you can work with client macros safely.

    How the checker was tested

    Every rule was tested against a large set of real-world macros. Rules that raised false alarms on working code were fixed or downgraded before release. Argument counts are based on how the functions are called in practice.

    What it cannot do

    It does not run your code and does not know your data model, so it cannot check attribute names, object types or results. Always test in OMP.
